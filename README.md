# 🚀 AWS RDS + EC2 MySQL Project

## 📌 Overview

This project demonstrates a real-world AWS database setup by connecting an Amazon EC2 instance with an Amazon RDS MySQL database.

The project includes MySQL database operations, snapshot backup creation, snapshot restore testing, and restored database verification.

---

## 🧱 Architecture

- Amazon EC2 Instance
- Amazon RDS MySQL Database
- Security Groups
- MySQL / MariaDB Client
- RDS Snapshot Backup & Restore

---

## ⚙️ AWS Services Used

- Amazon EC2
- Amazon RDS (MySQL)
- Security Groups
- Amazon Linux 2023
- RDS Snapshots

---

## 🔐 Security

- Secure EC2 to RDS Connectivity
- Database Authentication using MySQL
- Controlled Database Access
- Security Group Configuration

---

## 📈 Features

- EC2 to RDS Connection
- MySQL Database Administration
- Database & Table Creation
- Insert, Retrieve & Delete Data
- Manual Snapshot Backup
- Snapshot Restore Verification
